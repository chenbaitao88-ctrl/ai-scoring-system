# 城市无障碍出行助手

这是一个完全虚构的离线演示作品，用于展示无障碍需求建模、加权寻路和异常提示等作品证据。地图节点、路线和障碍信息均为自建演示数据，不对应真实地点或个人行程。

## 作品设想

使用者选择起点和终点后，程序比较路线距离、坡度、电梯和临时障碍，为行动不便人群推荐更合适的路线，并在没有可用路线时给出明确提示。

## 主要功能

- 读取自建的虚构地点与路径网络。
- 根据台阶、坡度和电梯情况计算无障碍成本。
- 推荐一条主路线并保留备选路线。
- 对封闭路径、未知地点和无解情况给出反馈。

## 文件说明

- `main.py`：虚构地图数据和演示查询入口。
- `route_planner.py`：加权寻路与路线说明逻辑。
- `ai-use-record.txt`：虚构的 AI 辅助使用与人工核对记录。
- `preview.svg`：路线推荐页面的静态界面示意图。

源码仅供离线演示和人工阅读，初始化脚本不会执行它。
