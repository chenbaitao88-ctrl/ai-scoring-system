# 校园节水小管家

这是一个完全虚构的离线演示作品，用于展示 AI Scoring System 如何读取作品附件并形成辅助评审意见。作品不对应任何真实学生、学校或比赛提交。

## 作品设想

同学每天记录洗手区、饮水区和绿化区的用水量。程序会汇总一周趋势，在用水超过虚构基线时给出提醒，并根据变化生成节水行动建议。

## 主要功能

- 登记不同场景的每日用水量。
- 计算一周总量和各场景占比。
- 识别超过虚构基线的日期。
- 输出适合校园宣传的节水建议。

## 文件说明

- `main.py`：使用固定演示数据实现记录、统计和提醒逻辑。
- `ai-use-record.txt`：虚构的 AI 辅助使用与人工核对记录。
- `preview.svg`：作品首页的静态界面示意图。

源码仅供离线演示和人工阅读，初始化脚本不会执行它。
