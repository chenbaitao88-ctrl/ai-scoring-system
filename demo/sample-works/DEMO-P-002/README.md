# 古诗词节奏训练营

这是一个完全虚构的离线演示作品，用于展示题库、即时反馈和学习统计等作品证据。作品不对应任何真实学生、学校或模型对话。

## 作品设想

学习者根据提示选择古诗词的朗读节奏。程序从小型示例题库中组题，判断答案后说明停顿位置，并统计本轮正确率。

## 主要功能

- 从固定的虚构题库生成练习。
- 对比学习者答案和参考节奏。
- 给出即时反馈与朗读提示。
- 汇总答题数量、正确数量和正确率。

## 文件说明

- `app.py`：题库读取、答案判断和统计逻辑。
- `ai-use-record.txt`：虚构的 AI 辅助使用与人工核对记录。
- `preview.svg`：答题页面的静态界面示意图。

源码仅供离线演示和人工阅读，初始化脚本不会执行它。
