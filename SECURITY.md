# Security and privacy

This repository contains source code and synthetic demo fixtures only.

- Never commit real student records, works, media, transcripts, cloud links, databases, or model responses.
- Never commit API keys, tokens, passwords, private endpoints, or `.env` files.
- Use synthetic identifiers and fictional names in tests and demonstrations.
- Keep live provider credentials in local environment variables only.
- Treat generated exports and runtime sidecars as local data and keep them outside Git.

If sensitive material is committed accidentally, stop using the repository and rotate affected credentials before any history repair.
